# 🚀 XAU/USD Trading Signal Bot (Moving Average Crossover)

Selamat datang di repositori algoritma trading saya! 
Proyek ini adalah sistem deteksi otomatis untuk menemukan momentum **BUY** dan **SELL** pada pergerakan harga emas (XAU/USD) menggunakan logika matematika dan analisis data.

## 💡 Latar Belakang
Sebagai mahasiswa Matematika dengan minat mendalam pada analisis finansial, saya membangun bot ini untuk menghilangkan faktor "emosi (FOMO)" dalam trading. Algoritma ini murni digerakkan oleh persilangan data historis (*Moving Average Crossover*).

## 🛠️ Fitur Utama
* **Otomatisasi Simple Moving Average (SMA):** Menghitung rata-rata pergerakan harga secara dinamis (SMA Cepat 3-Hari & SMA Lambat 5-Hari).
* **Scanner Sinyal Cerdas:** Mendeteksi **Golden Cross** (Sinyal BUY 🟢) dan **Death Cross** (Sinyal SELL 🔴) berdasarkan logika *If-Else*.
* **Visualisasi Finansial:** Mencetak grafik garis interaktif bergaya *dashboard trader* profesional.

## 💻 Teknologi yang Digunakan
* **Bahasa:** Python 3
* **Library Analisis:** Pandas
* **Library Visualisasi:** Matplotlib
